## The outcome

Give your OpenClaw agent a personality and operating style people can actually recognize. This skill covers 12 prebuilt souls, a guided interview, blending, audits, and export-ready SOUL.md files.

## What you get

A clear SOUL.md that shapes how the agent sounds, decides, and works without turning it into a corporate horoscope.

## Quick start

1. Install the ClawHub skill: `soul-md-maker`
2. Run `/soul-md-maker`
3. Start with the role, audience, voice, boundaries, and behaviors you want. Use the guided interview when those answers are fuzzy.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /soul-md-maker with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
